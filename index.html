The concrete workflow to build this week: connect your LLM to the tools you actually live in via MCP, hand it one real end-to-end task with “cite all your sources so I can validate” appended, then lock the successful pattern in as a reusable skill. Applied AI Workflows for PMs

Must read
Unpacking ChatGPT Work: the Agent for a Billion Users
Latent.Space (Shlok Khemani) · August 4, 2026
Key takeaway
Khemani reverse-engineers ChatGPT Work — the agent product OpenAI launched July 9 that reportedly crossed 10 million users in three weeks — and finds the interesting design choice is where continuity lives: the agent gets broad freedom inside a task’s scratch directory, but memory, files, and cross-thread context all route through an opinionated product layer rather than the computer itself. The non-obvious insight for PMs is his diagnosis of the weak link: with 1,000+ plugins available, Work routes seamlessly to what you’ve installed but never suggests a relevant plugin you’re missing, leaving value on the table for users and developers alike. Discovery, not capability, is the unsolved product problem in agent platforms — and if you own any surface where users must find the right extension or integration, that gap is the one worth designing for. Also worth stealing: his read on proactivity, where Work now suggests tasks inferred from your calendar and email but still waits for you to press go.
